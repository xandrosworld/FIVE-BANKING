# The Banking Five | VAIC 2026

Data-driven competition profiles for The Banking Five at Vietnam AI Innovation Challenge 2026.

## Run locally

```bash
pnpm install
pnpm dev
```

Open an implemented profile:

- `http://localhost:3000/mai-tan-thanh`
- `http://localhost:3000/duong-hoang-anh`
- `http://localhost:3000/karthikeyan-ramaswamy`
- `http://localhost:3000/nguyen-gia-huy`
- `http://localhost:3000/ho-khanh-quynh`

English is the default language. Add `?lang=vi` or use the page switcher for Vietnamese.

## Configuration

Copy `.env.example` to `.env.local` and set the real deployment origin:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.example
```

This value is used for canonical URLs, structured data, robots and sitemap output.

## Content model

- Shared interfaces live in `src/types/profile.ts`.
- Profile content and approved repositories live in `src/data/profiles.ts`.
- Shared rendering and interactions live in `src/components/profile-page.tsx`.
- Member routes are generated by `src/app/[slug]`.
- Member assets live in `public/images/<member-slug>`.

To add another member, provide a complete `MemberProfile` with both `en` and `vi` copy, add the assets under that member's slug, then add the profile to the exported `profiles` record.

## Quality checks

```bash
pnpm check
```

The check runs the content allowlist audit, ESLint, production build and Playwright tests. Browser tests cover 320, 375, 768, 1024 and 1440px widths, language switching, navigation, public links and horizontal overflow.
